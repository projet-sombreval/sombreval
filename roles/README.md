# roles/ — les fiches techniques des rôles

Un fichier par rôle, rangé dans le dossier de son univers :

- `roles/sombreval/` — Sombreval 1348
- `roles/salem/` — Salem 1692
- `roles/serenissime/` — Sérénissime 1487

Le nom du fichier est celui du rôle, en minuscules et sans accent :
`bailli.md`, `guerisseuse.md`, `inquisiteur.md`.

Une fiche de rôle sert à **écrire le code du jeu**. Elle répond à quatre
questions, dans cet ordre :

1. son pouvoir en **une** phrase vérifiable ;
2. **quand** il agit ;
3. **ce que le jeu doit vérifier** (la liste des règles à coder et à tester) ;
4. **pourquoi c'est équilibré**.

`sombreval/bailli.md` est la fiche de référence : pars de sa structure.

À ne pas confondre avec le dossier `cartes/`, qui contient ce que le **joueur**
voit à l'écran. Ici, c'est ce que le **programme** doit savoir.
