# Les écrans du jeu

<!-- ── À TOI · ARCHITECTE DES ÉCRANS ───────────────────
Le jeu n'a qu'une seule page, site/index.html. Tous ses
écrans sont fabriqués par site/js/jeu.js. Ce fichier en
est la carte : on la lira avant d'ouvrir jeu.js ensemble.

Cherche dans jeu.js les appels à dessiner(...) : chacun
fabrique un écran, à l'intérieur d'une fonction dont le
nom commence par « ecran ». Deux seulement reçoivent un
nom en dernier argument ; pour les autres, c'est le nom
de la fonction qui le dit.

Tu en trouveras sept. Le huitième ne passe pas par
dessiner : il se pose par-dessus l'écran en cours.
Trouve-le.

Une ligne par écran : son nom, la fonction qui le
dessine, et ce qu'il contient en trois mots. C'est fini
quand on peut dire, en lisant le tableau, quelle fonction
ouvrir pour modifier quoi.

Chaque ligne d'un tableau tient sur UNE SEULE ligne de
texte, même longue. Coupée en deux, elle ne s'affiche
pas.
