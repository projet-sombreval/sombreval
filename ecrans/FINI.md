# Quand est-ce qu'un écran est fini ?

Huit critères. Un écran qui n'en respecte pas un n'est pas fini : il est
renvoyé, avec le numéro du critère. Ce n'est pas un jugement de goût, et ça
ne se discute pas — ça se vérifie.

Cette liste vaut pour nos écrans **et** pour ceux que l'atelier design nous
livre : D3 la salle d'attente, D4 la carte de rôle, D5 l'écran de jour,
D6 l'écran de nuit, D7 l'écran final.

| | Le critère | Comment on vérifie |
|---|---|---|
| 1 | Les couleurs portent les mêmes noms de variables et les mêmes valeurs que les autres écrans | |
| 2 | Une seule police, et trois tailles de texte au maximum | |
| 3 | Tous les espacements sont pris dans l'échelle 4 · 8 · 16 · 24 · 32 | |
| 4 | Un seul modèle de bouton, partout | |
| 5 | Chaque champ de saisie a une étiquette visible, pas seulement un texte d'exemple | |
| 6 | On voit où on est quand on navigue à la touche Tab | |
| 7 | Rien ne déborde sur un écran large de 360 pixels | |
| 8 | Les états — désactivé, erreur, chargement — ne se reconnaissent pas à la couleur seule | |

Le critère 8 ne s'applique pas encore à nos deux premiers écrans, qui n'ont
pas d'états. Il s'appliquera à partir de la salle d'attente.
